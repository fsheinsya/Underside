# UI処理の担当

## Bet画面

| ファイル | 担当 |
| --- | --- |
| `BetSceneController` | Inspector参照、UnityEventの入口、操作受付のロック、画面遷移 |
| `BetAmountController` | 金額の直接入力、範囲補正、クリック・長押し、入力イベントの登録と解除 |
| `BetScenePresentation` | モンスターの初期表示、登場演出、詳細画面の開閉 |
| `BetPlacementService` | 賭け条件の検証、オッズ計算、`GameSession`への保存 |
| `StatusDetailView` | 左右共通の詳細表示とスライド演出 |

`LeftStatusDetailView`と`RightStatusDetailView`は既存シーンのスクリプト参照を維持するために残す。
両クラスは継承できない`sealed`にし、固定された左右の向きだけを定義する。
表示項目や演出を変更するときは`StatusDetailView`だけを修正する。
既存のSerializeField名、スクリプトGUID、Button / EventTriggerの公開メソッド名は維持している。

長押しは押した瞬間に1だけ変更し、0.3秒後から繰り返す。
繰り返し間隔は0.2秒から最短0.05秒まで短縮する。
同じボタンを押している実時間に応じて、1回の増減を次のように切り替える。

| 押し続けた時間 | 1回の増減 |
| --- | ---: |
| 0秒以上、5秒未満 | 1 |
| 5秒以上、10秒未満 | 10 |
| 10秒以上、15秒未満 | 100 |
| 15秒以上、20秒未満 | 1,000 |

以後も5秒ごとに10倍にし、刻み幅は最大10億、賭け金は所持コインを上限にする。
減額も同じ規則で最低1まで。所持コインが0のときだけ金額を0にする。
ボタンを離したとき、詳細表示、画面の無効化、フォーカス喪失、アプリの中断で長押しを停止する。
次に押すと刻み幅は1へ戻る。低フレームレートでも過去の繰り返しをまとめて加算しない。

## 結果画面・ランキング

`ResultSceneController`は次の画面へ進む直前、無効化時、破棄時に演出をキャンセルする。
すべてのTweenとコイン表示ループがキャンセルトークンを受け取り、キャンセル時はその画面のTweenを停止する。

`AllResultSceneController`は最終成績とランキング保存の判断を担当する。
確認パネルの生成、座標、サイズ、ボタン、上位5人の文字列表示は`RankingResultPanel`で管理する。

## 戦闘の被弾演出

`BattleSimulator`が技の実行前後の対象HPを比較し、行動ログの`TargetTookDamage`へ記録する。
`BattleEffectPlayer`はこの値がtrueの攻撃だけで対象の被弾モーション・被弾音を再生する。
技の失敗、回避、無敵、完全耐性、HP1のままの踏みとどまりでは被弾演出を出さない。

## 確認

Unityメニューの`Tools > UnderSide > Check UI Refactor`で、長押しの境界と上下限、実戦処理の被弾フラグ、
既存Betシーンの参照・イベント、左右の向き、ランキングの配置と操作、結果Tweenのキャンセルを検証する。
シーンの設定を保存する処理や、ランキングの永続保存は行わない。
